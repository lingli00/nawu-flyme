## 0. 一句话定位

一套 **React 18 + TypeScript** 前端，**同一份 `src/` 同时产出三种形态**：
Android App（Capacitor 7 壳）、手机网页、PC 网页。
数据 **100% 存在设备本地**（Capacitor Preferences / localStorage），
上云只走「整体快照备份」，服务端不持有业务数据。

> ⚠️ `README.md` 是项目早期的老文档（那时还叫「归否 Guifou」、`pages/` 还是占位），
> 目录说明已过时。**以本文件为准。**

## 2. 三条硬性架构约束（改代码前必读）

### 2.1 依赖方向只能向下
```
pages → store → domain/api → net → storage/lib
```
`pages/**`、`components/**` 内**禁止**裸 `fetch`，禁止直接 import
`CapacitorHttp` / `Preferences`。

### 2.2 网络出口唯一
所有请求走 `src/net/httpClient.ts`（内部做 CapacitorHttp ⇄ fetch 的运行时选择）。
POST 请求体一律 JSON —— 后端只读 `php://input` 做 `json_decode`，form 表单会被静默忽略。

### 2.3 本地键名与 ID 算法不得改
`guifou.<collection>`、`guifou.kv.*`、
`newId() = Date.now().toString(36) + Math.random().toString(36).slice(2,8)`，
快照 `app` 字段固定 `"guifou-web"` —— 否则与历史备份无法互通。
（名字带 `guifou` 是历史包袱，属于**存储层协议**，与产品改名无关。）

## 3. 三端一码：怎么做到一套代码三形态

运行时**壳探测**，不是编译期分支：

- 视口 `≥1024px` 或用户偏好 PC → 桌面壳（侧边栏 + 宽内容 + 多列）
- `<1024px` → 移动壳（底部 tab）
- Capacitor 原生环境（WebView 源为 `https://localhost`）→ 移动壳 + `isNative()` 分支

**页面级桌面布局必须用 shell 感知的 Tailwind 变体 `dt:` / `dtxl:` / `dt2xl:`**
（`≥1024` 且 `data-shell≠mobile`），**禁用裸 `lg:`** —— 否则手机横向或分屏时会串味。

## 4. 四个「单一真相源」（本项目的设计精髓）

| 真相源 | 文件 | 解决的问题 |
|---|---|---|
| **物品图标** | `src/lib/goodsIcon.ts` | 图标三形态（裸 id / `url:` / `img:`）+ 内置 / 品牌图片统一取值，渲染一律 `goodsIconValue + IconPreview`，**禁止硬编码** |
| **品牌图标** | `src/lib/brandIcon.ts` | 177 个品牌域名 → `public/brand-icons/<domain>.<ext>`（由 `_finalize_brand_assets.cjs` 生成 `src/generated/brandIconAssets.ts`）。取值一律 `brandIconRef/brandIconSrc/faviconChain` |
| **图标缓存** | `src/lib/iconCache.ts` | 内存索引 + 读备忘 + 400ms 防抖串行写 + 并发闸 4 + inflight 去重 + 10s 超时 |
| **写盘** | `src/storage/kv.ts` + `repo.ts` | 所有写走 `enqueueWrite()` 串行链；`persist()` 重试 3 次且**必须 resolve**，失败经回调弹 toast |

### ★「包内资源必须直出」铁律
凡「包里已有」的图（`/brand-icons/…`）渲染层一律**直出**，不许再进 iconCache/网络管线。
消费点：`IconPreview`、**`BrandImg`（易漏，品牌网格走它）**、`GlyphButton`。
必须返回**源站相对路径**（不要拼服务器地址，APK 里取不到）。
→ **改渲染取值前，先 grep 出全部消费点。**

## 5. 稳定性设计（吃过教训才有的）

- **启动**：`main.tsx` 先渲染骨架屏 → `bootstrap` try/catch（失败进 BootFatal）；
  根级 `ErrorBoundary` 崩溃时显示错误页 + 现场；`errlog.ts` 捕 window error/rejection → `flyme.errlog`。
- **网络**：`iconCache` 的 fetch **必须带 10s AbortController 超时** —— 无超时 = 并发闸槽位泄漏 = 图标永久空白。
- **弹层**：新弹层用 `useBackGuard` 处理返回键；默认**就地打开**、保存成功**必须关弹层**。
- **备份瘦身**：内置图存引用码；数据图 ≤100KB；icons 只带被引用条目。
  **实体新增图片字段必须同步 slim + 引用键 + 测试三处。**

## 6. 命令

```bash
npm run dev          # 开发服务器（Vite 代理 /api 到后端）
npm run typecheck    # tsc --noEmit，必须零错误
npm test             # vitest（只收 tests/**/*.test.ts）
npm run build        # typecheck + vite build → dist/
npm run cap:sync     # build + npx cap sync android
npm run check-env    # 打 APK 前的环境自检（JDK / SDK）
```

质量门基线：**tsc 零错 + 129 个单测全绿（19 个文件）+ build 成功**。
