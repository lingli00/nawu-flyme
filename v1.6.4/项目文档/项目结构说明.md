### 2.2 `src/` 分层（**依赖方向只能向下**）

```
pages  →  store  →  domain / api  →  net  →  storage / lib
```

| 目录                | 作用                                      | 什么时候改                  |
| ----------------- | --------------------------------------- | ---------------------- |
| `src/types/`      | 数据模型（`entities.ts` 业务实体 / `ai.ts` 解析草稿） | 加字段、加实体                |
| `src/lib/`        | 纯工具 + **单一真相源**（图标、版本、金额、日期、剪贴板、语音）     | 加通用能力                  |
| `src/storage/`    | 本地持久化（`kv.ts` 串行写链 / `repo.ts` 12 个集合）  | 改存取协议（**慎改键名**）        |
| `src/store/`      | Zustand 六个 store                        | 加全局状态、跨页动作             |
| `src/domain/`     | 业务纯函数（物品/账本/订阅/统计）                      | 改计算口径                  |
| `src/net/`        | 唯一 HTTP 出口（`httpClient.ts`）             | 改请求策略（**禁止页面裸 fetch**） |
| `src/api/`        | 后端接口封装 + 原生插件封装                         | 加接口、加插件                |
| `src/ai/`         | 一句话记账：解析、规则、分句、查询                       | **记一笔识别相关全部在这里**       |
| `src/pages/`      | 页面                                      | 改界面与交互                 |
| `src/components/` | 组件（含 `ui/` 基础组件、`layout/` 外壳）           | 改 UI 组件                |
| `src/generated/`  | 生成物（品牌图标表）**勿手改**                       | —                      |

### 2.4 原生层 `app/android`

```
android/app/src/main/java/com/guifou/app/
├── MainActivity.java      ★ 本地插件注册处（registerPlugin 必须在 super.onCreate() 前）
├── ApkUpdatePlugin.java   APK 下载 / 补丁合成 / 安装
```

### 3.1 服务端接口分区（`app/Api.php` 内按注释分节）

| 分区            | 路径前缀                                   | 说明                                |
| ------------- | -------------------------------------- | --------------------------------- |
| 健康检查          | `/api/health`                          | 返回 `{ok, db}`，部署验收第一站             |
| 认证            | `/api/auth/*`                          | 注册/登录/刷新/登出                       |
| 云备份           | `/api/backups*`                        | 整体快照上传/下载/列表                      |
| 物品 / 生活流 / 订阅 | `/api/*`                               | 与本地集合同构                           |
| 品牌图标          | `/api/brand/*`                         | 图标代理与缓存                           |
| 归属地           | `/api/geo`                             | IP → 省/市/区县 + 经纬度                 |
| App 更新        | `/api/app/version`、`/api/app/download` | 自有服务器通道（无补丁）                      |
| **服务端自更新**    | `/api/admin/server/*`                  | `status` 轮询即推进、`start`、`rollback` |
| 管理后台          | `/api/admin/*`                         | 登录、设置、SMTP 等                      |

> 路由名 `/api/admin/server/*` **必须跨版本保持稳定** —— 更新任务跨版本执行，  
> 换名字会让旧任务在「新代码」上找不到入口。

## 五、存储协议（**改之前先读**）

| 键 / 字段    | 值                                  | 注意                           |
| --------- | ---------------------------------- | ---------------------------- |
| 集合键       | `guifou.<collection>`              | 12 个集合（goods/valueRecords/…） |
| KV 键      | `guifou.kv.*`                      | 设置、登录态等                      |
| 快照        | `app: "guifou-web"`                | 备份互通标识，改名 = 老备份全废            |
| 登录态       | `flyme.sessions`                   | 按服务器 id 分槽                   |
| `newId()` | `Date.now().toString(36) + random` | ID 算法不可改                     |

名字带 `guifou` 是历史包袱，属于**存储层协议**，与产品改名无关，不要「顺手统一」。
