# 关于这个目录

本包**只排除了一个文件**：`config.php` —— 里面是数据库口令（服务器上权限 600），
不随任何发布包/备份分发。部署到新机器时，用你自己的库口令生成它（或从旧服务器单独取回）。

其余运行时内容都在包里：
- `brand-icons/` —— 品牌图标缓存（网页/App 的订阅图标兜底）
- `app-release/` —— 老客户端更新回退通道（`/api/app/version` 读它）
- `asr/` —— **未包含**（42MB 离线语音模型，体积太大，需要时单独上传）

完整部署说明见 `项目文档/部署记录-服务器.md`。
