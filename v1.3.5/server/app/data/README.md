# data 目录说明

## geo-cn.json

省市二级 IP 归属地兜底数据（约 170KB），随包下发，`IpLoc` 类在拿不到更细数据时使用。

## qqwry.dat（缺失，需自行放置）

`IpLoc` 的区县级定位依赖纯真 IP 库 `qqwry.dat`（GBK 编码，约 26MB）。该文件**未随本仓库下发**，原因：

- GitHub 的 Git Blob API 对单次请求体有实际约 10MB 的上限，26MB 文件（base64 后约 35MB）会被边缘代理以误导性的 `401 Bad credentials` 拒绝，无法通过 API 上传；
- 纯真库为第三方免费数据，随源码仓库分发存在许可与更新时效问题。

**放置方式**（可选，不影响其他功能）：

1. 从公开镜像下载 `qqwry.dat`（任选其一，注意校验为 GBK 版约 26MB）；
2. 放到本目录：`server/app/data/qqwry.dat`；
3. 无需改代码，`IpLoc` 自动识别；缺失时静默返回 null，前端降级为「只显示省市」，不会白屏。

区县级定位仅为体验增强，登录、记账、同步等核心功能不依赖它。
